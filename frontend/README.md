# Frontend Module

> React + Vite web dashboard for the Smart Energy Monitoring System.

## Status: Phase 5 (Not yet implemented)

This directory will contain:
- `src/pages/` – Page components (Dashboard, Login, Areas, etc.)
- `src/components/` – Reusable UI components (Charts, Cards, Tables)
- `src/services/` – API client and authentication service
- `src/context/` – React context for state management
- `public/` – Static assets
